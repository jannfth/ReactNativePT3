# 📱 React Native PT3 App

Repositori ini berisi proyek pengembangan aplikasi mobile menggunakan **React Native**. Proyek ini dibuat sebagai bagian dari tugas pembelajaran pemrograman perangkat bergerak dengan fokus pada pembangunan antarmuka lintas platform (*cross-platform*), pengelolaan komponen, serta navigasi aplikasi.

---

## 📱 Tentang Aplikasi
Aplikasi ini dikembangkan dengan React Native untuk mengeksplorasi pembuatan antarmuka pengguna berbasis JavaScript/TypeScript yang responsif dan dapat berjalan di berbagai sistem operasi seluler.

## 📋 Prasyarat Pembuatan
Sebelum mulai merancang, menginstal, atau menjalankan aplikasi React Native ini, pastikan komputer kamu telah menyiapkan beberapa hal berikut:
* **Node.js & npm/yarn:** Diperlukan untuk menjalankan lingkungan JavaScript dan mengelola paket dependensi proyek.
* **Perangkat Lunak / IDE:** Menggunakan *Visual Studio Code* atau editor kode pilihan lainnya.
* **Perangkat Pengujian:** Menggunakan emulator Android/iOS di komputer, atau aplikasi **Expo Go** / perangkat fisik melalui USB debugging.

---

## ✨ Fitur Utama
* **Antarmuka Lintas Platform:** Dibangun menggunakan komponen React Native yang fleksibel dan responsif.
* **Manajemen State & Navigasi:** Pengelolaan alur layar dan data antar komponen secara efisien.
* **Struktur Kode Modular:** Pemisahan komponen dan logika aplikasi yang rapi agar mudah dikembangkan.
